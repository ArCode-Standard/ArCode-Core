# Security Policy

## Reporting a Vulnerability

We take the integrity of the ArCode Standard seriously. If you discover a
security issue in this repository — including in `validate.js`, the CI
configuration, or any part of the tooling — please report it privately.

- **Email:** open a [private security advisory](https://github.com/ArCode-Standard/ArCode-Core/security/advisories/new) on GitHub
- **Do not** open a public issue for security vulnerabilities

We will acknowledge receipt within 3 business days and work on a fix before
disclosure.

## Scope

The `dictionary.json` file contains terminology data only; it is not
security-sensitive by itself, but contributions are still reviewed.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |
