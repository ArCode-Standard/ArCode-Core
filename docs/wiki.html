ما هو ArCode Standard؟

الرؤية

ArCode Standard هو معيار مفتوح المصدر لتوحيد المصطلحات العلمية والتقنية العربية. يوفّر قاموساً ثنائي اللغة (عربي-إنجليزي) لكل مصطلح، مع تعريف دقيق من مصادر معيارية عالمية، بحيث يتكلم المهندسون والعلماء والمطورون «لغة واحدة» بالعربية.

لماذا نحتاج إليه؟

  • الترجمة الحرفية تنتج مصطلحات مختلفة لنفس المفهوم عبر المصادر.
  • المعيار يوفر مرجعاً موحداً قابلاً للاعتماد في التعليم والبرمجيات والوثائق.
  • ربط كل مصطلح بمعرّف ACS ثابت يسمح بالاعتماد عليه في الأنظمة البرمجية.

النطاق (المجالات)

يغطي المعيار 18 مجالاً علمياً، لكل مجال 1,000 مصطلح معتمد (إجمالي 18,000):

GEN · CS · AI · NET · SEC · MATH · PHYS · BIO · CHEM · ENG · MED · LING · ECON · LAW · AGR · ASTR · GEO · STAT

ما الذي يتكوّن منه المشروع؟

ArCode Core هو مشروع مفتوح المصدر يجمع بين البيانات والمعايير والوثائق، ويهدف إلى توفير مصدر موحّد للمصطلحات العلمية العربية عبر بيئة قابلة للتنفيذ في الويب، API، والحزم البرمجية.

  • البيانات: ملف dictionary.json يحتوي على المصطلحات الأساسية وحقولها المعيارية.
  • الواجهة: مجلد docs/ يحتوي على الموقع التوثيقي الرسمي، بما في ذلك الصفحة الرئيسية، API، وWiki.
  • البرمجة: ملف index.js يوفر واجهة JavaScript قابلة للاستخدام في Node.js أو المتصفح.
  • التحقق: ملفات التحقق مثل validate.js و test.js تضمن اتساق البيانات وجودة التحديثات.

كيف يعمل المشروع عملياً؟

  1. يتم جمع المصطلحات من مصادر معيارية موثوقة وتوحيدها في شكل متجانس.
  2. يُخزن كل مصطلح مع معرّف ACS ثابت، وتعريفه بالعربية والإنجليزية، ومجاله العلمي، ومصدره المرجعي.
  3. تُعرض البيانات في شكل قاموس بشكل مباشر على الموقع، أو عبر واجهة برمجة تتيح الاستعلام والبحث.
  4. تتم مراجعة التغييرات عبر التحقق الآلي قبل النشر، لتبقى البيانات متسقة وقابلة للاعتماد.

لماذا يعتبر هذا المشروع مهمًا؟

الهدف ليس مجرد جمع كلمات، بل بناء قاعدة معرفية موحدة تخلّي بين اللغة العربية والعالمية. هذا مهم للبرامج، التعليم، البحث، والوثائق التقنية، لأن الاستخدام المتكرر لمصطلحات مختلفة يسبب التشتت والارتباك.

من خلال ArCode، يكتسب الفريق أو المؤسسة مرجعًا واحدًا يمكن الرجوع إليه في كل مشروع، بدلًا من الاعتماد على ترجمات متفرقة أو اصطلاحات محلية غير موحّدة.

كيف تساهم في المشروع؟

إسهامك مرحب به إذا كنت تخطط لتطوير المصطلح نفسه، أو تحسين البيانات، أو تطوير الموقع أو واجهة API. يمكنك البدء من:

  • اقتراح مصطلح جديد أو تعديل مصطلح موجود عبر GitHub.
  • تحسين التوثيق أو توضيح أجزاء Wiki وAPI.
  • إضافة دعم أو اختبارات أو تحسينات على واجهة الاستخدام.
  • مراجعة أو تجهيز بيانات المجالات المنقحة قبل التحديث النهائي.

المخرجات المتاحة للمستخدم

  • قاموس بحث مباشر عبر الموقع الرسمي.
  • ملفات JSON ثابتة يمكن استهلاكها من أي نظام أو تطبيق.
  • واجهة برمجة API بسيطة للبحث حسب المصطلح أو المعرف أو المجال.
  • حزمة npm قابلة للاستخدام في Node.js.

نظام المعرّفات (ACS ID)

كل مصطلح له معرّف فريد من الشكل:

ACS-<DOMAIN-CODE>-<NUMBER>

مثال: ACS-CS-0042 مصطلح علوم الحاسب رقم 42. المعرّف ثابت ولا يتغير، حتى لو تعدّل النص.

بنية البيانات

Fieldالوصف
ACS_IDالمعرّف الفريد.
AR_TERMالمصطلح العربي.
EN_TERMالمصطلح الإنجليزي المقابل.
DOMAINالمجال العلمي.
DEFINITION_AR / DEFINITION_ENالتعريف باللغتين.
STATUSحالة المراجعة.
SOURCEالمصدر المرجعي.

المنهجية

  1. تحديد المجالات العلمية الـ 18 ذات الأولوية.
  2. جمع المصطلحات من معايير عالمية (ISO، IEEE، وغيرها).
  3. المراجعة اللغوية والدقيقة لكل مصطلح وتعريفه.
  4. اعتماد المصطلح وتوليد معرّف ACS فريد.

الجوانب التقنية

  • البيانات: dictionary.json (JSON موحّد).
  • حزمة npm: arcode-core مع دوال search / byId / byDomain / domains.
  • واجهة برمجة: ملفات JSON ثابتة على GitHub Pages. راجع صفحة API.
  • رخصة مفتوحة المصدر، والمساهمة عبر GitHub.
