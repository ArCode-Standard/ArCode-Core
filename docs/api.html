واجهة برمجة ArCode (API)

البيانات منشورة كملفات JSON ثابتة على GitHub Pages، ويمكن استخدامها مباشرة من أي لغة برمجة أو من المتصفح.

النقاط المتاحة (Endpoints)

Endpointالوصف
/dictionary.jsonالقاموس الكامل (18,000 مصطلح).
/api/domains.jsonقائمة المجالات وعدد المصطلحات في كل مجال.
/api/stats.jsonإحصاءات المشروع وبياناته الوصفية.

الرابط الأساسي (Base URL)

https://arcode-standard.github.io/ArCode-Core

حقول المصطلح

Fieldالوصف
ACS_IDمعرّف فريد للمصطلح.
AR_TERMالمصطلح بالعربية.
EN_TERMالمصطلح بالإنجليزية.
DOMAINاسم المجال العلمي.
DEFINITION_ARالتعريف بالعربية.
DEFINITION_ENالتعريف بالإنجليزية.
STATUSحالة المراجعة (Approved).
SOURCEالمرجع أو المصدر المعياري.

مثال — JavaScript (المتصفح)

// استخدم مكتبة العميل أو fetch مباشرة
import { ArCodeAPI } from "https://arcode-standard.github.io/ArCode-Core/api.js";

const api = new ArCodeAPI();
const results = await api.search("خوارزمية");
const term = await api.byId("ACS-CS-0042");
const domains = await api.domains();

مثال — Python

import json, urllib.request

base = "https://arcode-standard.github.io/ArCode-Core"
with urllib.request.urlopen(base + "/dictionary.json") as r:
    data = json.load(r)

terms = [t for t in data["terms"] if "algorithm" in t["EN_TERM"].lower()]
print(len(terms), "results")

مثال — cURL

curl https://arcode-standard.github.io/ArCode-Core/api/domains.json

حزمة npm

يمكنك أيضاً استخدام الحزمة الرسمية في Node.js:

npm install arcode-core

const { search, byId, byDomain, domains } = require("arcode-core");
console.log(search("نظام", { limit: 10 }));
